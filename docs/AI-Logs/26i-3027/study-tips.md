## 1. Objective

Create a Study Tips page that provides useful academic content for students, increases engagement, and offers a structured way to browse educational articles.

## 2. Prompt / Task Description

Develop a Study Tips and Blog page for FASTutor that matches the website's existing UI and branding.

The page should include:
- A featured article section
- Category tabs for Exam Prep, Time Management, Career, and Course Guides
- Article cards
- Author information
- Estimated reading time
- Article publication dates
- A search field to filter articles
- An article-reading interface
- A newsletter signup form UI

The layout should be responsive and maintain a consistent visual style with the main FASTutor website.

## 3. Implementation Approach

- Create a featured article layout.
- Organize articles using category filters.
- Include article metadata such as author, date, and read time.
- Implement search functionality.
- Provide an article view for reading selected content.
- Add a newsletter signup interface.
- Use dedicated CSS and JavaScript files.
- Keep page styles isolated from the global stylesheet.
